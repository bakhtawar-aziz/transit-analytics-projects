# Project 1 - Fleet Reliability & Mileage Analytics
> **All data is SYNTHETIC**, generated by `src/generate_data.py` (seeded). Not agency data.

Run: `pip install pandas numpy matplotlib openpyxl` then `python run_all.py`

| Step | Script | Output |
|---|---|---|
| Generate raw dirty data | `src/generate_data.py` | `data/raw/*.csv` |
| Data-quality checks + cleaning | `src/data_quality.py` | `data/clean/`, `output/error_log.csv`, `quarantine.csv` |
| Load SQL database | `src/build_db.py`, `sql/schema.sql` | `output/fleet.db` (SQLite; views hold the KPI SQL) |
| Mileage audit | `src/mileage_audit.py` | `output/mileage_audit.csv`, `division_month_reconciliation.csv` |
| KPIs | `src/kpis.py` | `output/fleet_reliability_kpis.xlsx` + CSVs |
| Dashboard + summary | `src/dashboard.py` | `output/dashboard.html`, `docs/FINDINGS.md` |

KPI definitions: failures per 100,000 km = failures/km x 1e5; MDBF = km/failures; availability = non-out-of-service vehicle-days / all vehicle-days. Checks: DQ01 duplicates, DQ02 inconsistent entries, DQ03 missing, DQ04 range/logic, DQ05 traceability. Audit: A division-month reconciliation (+/-0.5%), B implied speed, C km while not in service, D missing vehicle-days, E failure on a non-service day.
